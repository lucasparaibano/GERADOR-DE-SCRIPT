Gerador de Script de OS — DTEL Telecom

Aplicativo web (HTML único, sem backend) para técnicos de campo montarem rapidamente o texto padrão de fechamento de ordem de serviço, evitando digitar tudo manualmente a cada atendimento.

Funcionalidades
Seleção da categoria da atividade: Instalação, Transferência, Suporte, Ativação/Adequação PPPoE, Mudança de Cômodo, Upgrade, Troca de Equipamentos, Entrega de Chip, Ponto de Rede, Instalação Roteador Mesh e Retirada
Campos de identificação (O.S., cliente, técnico) e equipamentos (ONU, PON, roteador, SN, CTO, DBM com controle deslizante e justificativa quando elevado)
Dados de rede (Wi-Fi, senha) e observações da visita
Lista de materiais utilizados com quantidade por item
Controle de contrato assinado e ponto de rede instalado, com campo de justificativa quando "não"
Checklist de aplicativos instalados no cliente e equipamentos conectados
Formulário específico para Retirada de equipamentos, com campos próprios (modelo da ONU, serial, quantidades de material recolhido etc.)
Geração do script em tempo real, pronto para copiar com um toque e colar direto na OS
Funciona 100% no navegador — não depende de servidor ou banco de dados
Como usar

Abra o index.html (ou acesse a versão publicada via GitHub Pages), escolha a categoria da atividade, preencha apenas os campos que mudam em relação ao padrão e toque em COPIAR SCRIPT.
